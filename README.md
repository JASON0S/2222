# Bloom Hands · 小屋花园

## 打开
下载 index.html 可直接打开预览，背景照片已嵌入文件，不需要单独下载素材。
摄像头请用 VS Code 的 Live Server 打开，并允许权限。首次加载手部识别模型需要联网。

## 八种花
蔷薇、雏菊、波斯菊、百合、向日葵、薰衣草、郁金香、虞美人。花朵为代码绘制的立体风格花型，并非写实三维扫描模型。

## 手势操作
1. 单手仅伸出食指，保持 0.8 秒：在指向的草地种植。
2. 食指、中指、无名指伸出：保持片刻切换花种。
3. 靠近花冠，拇指食指捏住：移栽，松手放下。
4. 靠近花冠，拇指中指捏合：采下一片花瓣。
5. 摆动张开的手掌：微风与落瓣。
6. 双手张开并稳定保持约 0.7 秒：降雨，保留原有动作。先识别挥手，再识别稳定张开的双手，避免与微风混淆。
7. V 手势保持片刻：昼夜切换，松开后可再次触发。
8. 拇指小指伸出、其余收起：召唤蜜蜂。
9. 握拳保持片刻：静赏/恢复。
10. 双手食指指尖相碰：花园苏醒、舒展动画。

## 鼠标预览
底部选花；点击草地种植；拖动花移动；双击花冠采瓣。右侧有指导，画面右上方工具可召唤蜜蜂、切换昼夜、暂停摇曳。

新增植物的位置限制在前景草地范围，数量上限 42。摄像头手势未在你的设备上实测，识别取决于光照和手掌朝向。视频在浏览器内处理，不录制或上传。
